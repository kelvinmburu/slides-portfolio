## Running locally

No build step. Either:

- Open `index.html` directly in a browser, or
- Serve it locally: `python3 -m http.server 8000` then visit `http://localhost:8000`

## Deploying

Hosted for free on GitHub Pages from the `main` branch. To update the live site:

```bash
git add .
git commit -m "Update site"
git push
```

GitHub Pages rebuilds automatically within a minute or two of each push.
